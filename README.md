YukkuriMovieMaker4（YMM4）上で動作する、**映像の輝度に応じてシャドウ・ミッドトーン・ハイライトの3色にグレードする色調補正エフェクトプラグイン**です。
HLSL ピクセルシェーダーを Direct2D カスタムエフェクトとして実装しており、GPU 上でのリアルタイムレンダリングが可能です。
カラーグレーディングの補間処理は知覚的に均一な **Oklab 色空間** 上で行われるため、自然で滑らかな色調変化が得られます。
中間調位置・不透明度・合成モードはキーフレームアニメーションに対応しています。

## 概要
 
本プラグインは YMM4 の「エフェクト」として動作します。対象アイテムに対して、輝度値に基づき**シャドウ**・**ミッドトーン**・**ハイライト**の3色をリアルタイムでマッピングします。
 
内部的には Direct2D カスタムピクセルシェーダーエフェクト（`D2D1CustomShaderEffectBase`）として実装されており、HLSL コンパイル済みシェーダー（`.cso`）をエフェクトチェーン上で動作させます。
 
入力ピクセルの sRGB 値をリニア空間へ変換し、BT.709 係数による知覚輝度を算出します。その輝度を `MidPosition` を境界とした二段階区間に分割し、Oklab 色空間上で各カラー間を線形補間することで知覚的に自然なグラデーションを生成します。最終的に sRGB へ戻した値を、アルファ乗算済みの形式で出力します。
 
出力矩形は入力矩形と同一です。本エフェクトはピクセル単位の色調変換のみを行うため、出力範囲の拡張は発生しません。

## インストール方法
 
1. [Releases](https://github.com/routersys/YMM4-Tritone/releases/latest) ページから最新のプラグインファイル（`.ymme`）をダウンロードしてください。
2. YMM4 が起動していないことを確認し、ダウンロードしたファイルを実行（ダブルクリック）してインストールします。
3. YMM4 を起動し、タイムライン上のアイテムに映像エフェクトを追加します。
4. 映像エフェクトの種類として **「トライトーン」** を選択してください。

## 主な機能
 
### 1. トライトーンの描画
 
入力映像の各ピクセルの輝度を BT.709 加重係数（R: 0.2126 / G: 0.7152 / B: 0.0722）で算出し、その値に応じてシャドウ・ミッドトーン・ハイライトの3色へリマップします。暗部・中間部・明部それぞれに任意の色を割り当てることで、映画調のルックや特定のムードを演出することができます。
 
### 2. Oklab 色空間による補間
 
色の補間は、知覚的に均一な **Oklab 色空間** 上で行われます。通常の sRGB や線形 RGB 空間での補間に比べ、明度・色相の変化が人間の視覚特性に沿った自然な曲線を描くため、不自然な彩度のピークや色相ずれが生じません。
 
輝度が `MidPosition` 以下の範囲ではシャドウカラーとミッドトーンカラーの間を補間し、`MidPosition` 超の範囲ではミッドトーンカラーとハイライトカラーの間を補間します。
 
### 3. 合成モードと不透明度
 
エフェクトの最終出力は **合成モード** と **不透明度** によって元映像とブレンドされます。
 
合成モードには Direct2D の Composite（構成）系と Blend（混合）系の両方に対応しており、映像の性質や演出意図に合わせて選択できます。デフォルトは `Normal`（通常合成）です。不透明度を下げることでエフェクトの適用強度を連続的に調整でき、原映像との自然な馴染みが得られます。
 
内部的には合成モードの種類に応じて `D2DEffects.Composite` または `D2DEffects.Blend` を動的に切り替え、その出力を `D2DEffects.CrossFade` へ渡すことで不透明度ブレンドを実現しています。
 
### 4. キーフレームアニメーション
 
`中間調位置` と `不透明度` の2パラメータはキーフレームアニメーションに対応しています。時間経過にあわせてエフェクトを徐々に出現・消滅させたり、輝度の境界位置をアニメーションさせたりする演出が可能です。

## アルゴリズム
 
各出力ピクセル **P** に対して以下の処理を行います。
 
1. **アルファ確認**: 入力ピクセルのアルファ値が 0 以下の場合、処理をスキップしてそのまま出力します。
2. **色空間変換**: アルファ除算によりストレート sRGB を算出し、ガンマ展開（sRGB → リニア RGB）を適用します。
3. **輝度算出**: リニア RGB に BT.709 輝度係数 `(0.2126, 0.7152, 0.0722)` を内積し、知覚輝度 `lum` を得ます。
4. **Oklab 変換**: シャドウ・ミッドトーン・ハイライトの各カラーを、sRGB → リニア RGB → Oklab の順で変換します。
5. **補間**:
   - `lum <= MidPosition` の場合: `t = lum / MidPosition` として、Oklab 空間でシャドウとミッドトーンを `lerp(shadow, midtone, t)` で補間します。
   - `lum > MidPosition` の場合: `t = (lum - MidPosition) / (1.0 - MidPosition)` として、Oklab 空間でミッドトーンとハイライトを `lerp(midtone, highlight, t)` で補間します。
6. **逆変換・出力**: 補間結果を Oklab → リニア RGB → sRGB と戻し、入力のアルファ値を乗じてアルファ乗算済み形式で出力します。
`MidPosition` を中央（0.5）より低く設定すると中間調領域が輝度の低い側に寄り、ハイライトが広く表現されます。逆に高く設定するとシャドウの占める範囲が広がります。

## 使い方ガイド
 
### 基本的な使い方
 
1. タイムライン上のアイテムを選択し、エフェクトを追加します。
2. 映像エフェクトの種類として **「トライトーン」** を選択します。
3. **シャドウ**・**ミッドトーン**・**ハイライト** に任意の色を設定します。デフォルトは暗紫・赤系・暖色クリームの組み合わせです。
4. **中間調位置** を調整して、色が切り替わる輝度境界を決めます。
5. **不透明度** と **合成モード** で元映像とのなじみを整えます。
### 映画調のルックを作る
 
シャドウに青みがかった暗色、ハイライトに暖色を割り当てることで、いわゆる「オレンジ＆ティール」風のカラーグレードを手軽に再現できます。不透明度を 60〜80 % 程度に下げることで元映像の質感を残しながら色調を演出できます。
 
### モノクロ・デュオトーン表現
 
シャドウとハイライトに2色を設定し、ミッドトーンをその中間色に近い色にすると、デュオトーン（二色刷り）のような表現になります。シャドウ・ミッドトーン・ハイライトをすべてグレースケール上の色にするとモノクロ変換としても機能します。
 
### エフェクトをフェードイン・フェードアウトさせる
 
`不透明度` パラメータのキーフレームを設定することで、クリップの開始・終了に合わせてエフェクトをなめらかに出現・消滅させることができます。たとえば 0 フレーム目に `不透明度 = 0`、30 フレーム目に `不透明度 = 100` のキーフレームを設定すると、約1秒かけてトライトーンが出現するアニメーションになります。
 
### 中間調位置をアニメーションさせる
 
`中間調位置` のキーフレームを設定することで、輝度の境界が時間とともに変化するダイナミックな色演出が可能です。値が増加するとシャドウ領域が広がり、減少するとハイライト領域が広がります。
 
### 合成モードを活用する
 
`合成モード` を `Normal` 以外に設定すると、トライトーン結果と元映像をさまざまな方法でブレンドできます。スクリーンやオーバーレイなどを選ぶことで、色調補正とは異なる独自の発光・質感表現が得られます。

## 注意事項
 
- **AviUtl 非対応**: 本プラグインは HLSL ピクセルシェーダーおよび Direct2D カスタムエフェクトを使用しているため、AviUtl 形式（`.exo`）への出力には対応していません。
- **3色カラーのアニメーション非対応**: `シャドウ`・`ミッドトーン`・`ハイライト` は `Color` 型であり、キーフレームアニメーションには対応していません。
- **合成モードのアニメーション非対応**: `合成モード` は列挙型であり、キーフレームアニメーションには対応していません。
- **中間調位置の有効範囲**: `中間調位置` の内部有効範囲は 1〜99（%）です。シェーダー内でゼロ除算を防ぐため、0 および 100 は設定できません。
- **出力矩形の変化なし**: 本エフェクトはピクセル単位の色調変換のみを行うため、出力矩形は常に入力矩形と同一です。エフェクトの追加による出力範囲の拡張は発生しません。
- **本プラグインを使用する前に、YMM4 プロジェクトファイルのバックアップを作成することを推奨します。**
